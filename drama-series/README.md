# 🎬 סדרת המתח: מנוע העריכה

כל פרק של הסדרה יוצא מכאן **באותו פס עיצובי בדיוק**: אותו צבע, אותם פונטים, אותו כרטיס פתיחה, אותו סאונד ואותו סיום.
אתה מביא תמונות וטקסט מ-GPT, והמנוע מרכיב מהם פרק מוכן להעלאה לטיקטוק ולאינסטגרם.

---

## איך כל פרק בנוי (קבוע בכל הסדרה)

| זמן | מה קורה |
|---|---|
| 0–3 שנ׳ | **הוק**: "פלאש-פורוורד" מרגע שיא בפרק. גליץ׳, טקסט שמופיע מילה-מילה, ו"מבוסס על סיפור אמיתי" מוקלד בפינה. |
| 3–7 שנ׳ | **כרטיס פתיחה**: שקט של חצי שנייה, ואז BRAAM קולנועי + **שם הסדרה · עונה X · פרק Y** + שם הפרק. |
| הגוף | סצנות: תמונות בתנועת מצלמה, כתוביות עם מילים מודגשות באדום, מיקום/שעה מוקלדים, הודעות טלפון, דופק, גשם, פלאשבק... |
| סוף | **קליפהנגר**: מוזיקה עולה ← חיתוך חד לשחור ← שקט ← בום ← **"המשך יבוא..."** + הפרק הבא + "עקבו". |
| סיום | **כרטיס "מבוסס על סיפור אמיתי"**: הכותרת מהבהבת כמו ניאון, והשורות נחשפות אחת-אחת עם קו אור אדום: *השמות שונו כדי לא לפגוע באיש · לעלילה נוספו תוספות לצורכי בידור*. |

בנוסף לכל פרק נוצרת **תמונת קאבר** אחידה (פרק X בגדול), כך שהפרופיל באינסטגרם ובטיקטוק נראה כמו עמוד של סדרת נטפליקס.

פורמט: ‎1080×1920 · ‏30fps · ‏H.264 + AAC · עוצמה ‎-16 LUFS. מתאים ישירות לטיקטוק, לרילס ולשורטס.

## מה אתה שולח לי לכל פרק

1. **התמונות** מ-GPT (אנכיות, ‎1024×1536). מספרים לפי הסדר: `01.png`, `02.png`...
2. **הטקסט/התסריט** מ-GPT: מה קורה בכל תמונה ומה כתוב עליה.
3. (אופציונלי) קריינות או מוזיקה.

הדרך הכי נוחה: ב-GitHub נכנסים לתיקייה `drama-series/episodes/`, יוצרים תיקייה בשם `s01e01` ומעלים אליה את התמונות (Add file ← Upload files). אחר כך כותבים לי "פרק 1 עלה", ואני כותב את קובץ הפרק, מרנדר ומחזיר סרטון וקאבר.

> רוצה שהטקסטים מ-GPT יגיעו כבר מוכנים? ב-[`GPT_GUIDE.md`](GPT_GUIDE.md) יש פרומפט-מאסטר שמדביקים ב-ChatGPT, והוא מוציא את הפרק בדיוק בפורמט של המנוע, יחד עם פרומפטים לתמונות באותו סגנון.

## קובץ פרק: `episodes/s01e01/episode.yaml`

```yaml
season: 1
episode: 1
title: "הלילה שבו הכל התחיל"
hook: "שלוש דקות. זה כל מה שנשאר לו *לפני שהדלת נפתחה.*"
hook_image: 05.png                # תמונת השיא שמוצגת בהתחלה

scenes:
  - image: 01.png
    stamp: "תל אביב · 03:17"      # מוקלד בפינה
    text: "העיר ישנה.\nרק הוא *לא.*" # *כוכביות* = אדום. \n = שורה חדשה
    effect: rain

  - image: 02.png
    message: { from: "מספר חסוי", time: "03:19", text: "אני יודע מה עשית בשבת." }
    effect: heartbeat

  - card: "72 שעות קודם"           # כרטיס מעבר שחור

  - image: 03.png
    effect: [flashback, rain]
    text: "הכל התחיל *בפגישה אחת*"

  - image: 05.png
    transition: flash
    effect: [flicker, shake]
    text: "ומישהו כבר חיכה לו\n*מאחורי הדלת.*"

next: "פרק 2 · מחר ב־20:00"
```

### אפקטים (`effect`)
| אפקט | מתי להשתמש |
|---|---|
| `rain` | גשם על המסך, לסצנות לילה ורחוב |
| `heartbeat` | דופק: זום פועם, שוליים אדומים וסאונד לב. לרגעי פחד |
| `glitch` | שיבושי מסך דיגיטליים: האקרים, מצלמות אבטחה, משהו "לא בסדר" |
| `flicker` | אור מהבהב: מסדרונות ומקומות מפחידים |
| `shake` | מצלמה רועדת: מרדף, בהלה |
| `red` | גוון אדום מאיים: סכנה |
| `flashback` | שחור-לבן חמים, לזיכרונות ו"קודם לכן" |

### תנועת מצלמה (`move`)
`zoom_in` · `zoom_out` · `push` (זום דרמטי מהיר) · `pan_left` · `pan_right` · `pan_up` · `pan_down` · `still`
ברירת המחדל מתחלפת אוטומטית. `focus: [0.3, 0.4]` מכוון את הזום לנקודה בתמונה (x, y מ-0 עד 1).

### מעברים (`transition`)
`fade` (ברירת מחדל) · `dip` (דרך שחור) · `flash` (הבזק לבן + בום) · `glitch` · `cut`

### עוד אפשרויות
- `duration: 4.5`: אורך הסצנה בשניות. בלי זה המנוע מחשב לבד לפי כמות הטקסט.
- `voice: 01.mp3`: קריינות לסצנה. הסצנה מתארכת אוטומטית לפי אורך הקריינות, והרקע מונמך מתחתיה.
- `voiceover: vo.mp3` (ברמת הפרק): קובץ קריינות אחד לכל הפרק.
- `music: theme.mp3`: מוזיקה משלך (אפשר גם קבועה לכל הסדרה ב-`series.yaml`).
- `hit: true`: בום על תחילת הסצנה.
- `cover: true` על סצנה: התמונה שלה תהיה הקאבר.

## זהות הסדרה: `series.yaml`
שם הסדרה, הצבע, טקסט "המשך יבוא", ה-CTA וטקסט הסיום. **משנים פעם אחת, וזה חל על כל הפרקים.**

## הרצה (בשבילי)
```bash
python3 engine/render.py episodes/s01e01             # → output/S01E01.mp4 + S01E01_cover.jpg
python3 engine/render.py episodes/s01e01 --preview   # + דף תמונות לבדיקה מהירה
python3 engine/render.py episodes/s01e01 --frames-only
```
דרישות: Python 3 עם numpy, Pillow, PyYAML, ו-ffmpeg. הפונטים (Frank Ruhl Libre ו-Heebo, ברישיון OFL) כלולים בתיקייה `engine/fonts`.

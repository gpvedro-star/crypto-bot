# 🎬 הירוקים: מנוע העריכה של הסדרה

כל פרק יוצא מכאן **באותו פס עיצובי**: אותם פונטים, אותן כתוביות, אותו פתיח עם עונה ופרק, אותו כרטיס סיום ירוק.
החומרים מגיעים מ-GPT (תמונות + תסריט), ההקלטה מ-Higgsfield, והמנוע עורך את הכול ומייצא.

## התוצרים של כל פרק (`output/`)
| קובץ | מה זה |
|---|---|
| `episode-XX.mp4` | רילס אנכי ‎1080×1920, ‏30fps, ‏H.264 + AAC, עוצמה ‎-14 LUFS, כתוביות צרובות |
| `episode-XX.srt` | התמלול המסונכרן, UTF-8 |
| `episode-XX_narration.wav` | הקריינות לבד, כמו שהיא יושבת בציר הזמן |
| `episode-XX_timing.json` | זמני כל מילה, כתובית ושוט |
| `episode-XX_cover.jpg` | קאבר לפרופיל |

עותק של ה-SRT, ה-timing והקריינות (m4a) נשמר גם בתיקיית הפרק, יחד עם הפרויקט.

## איך מפיקים פרק חדש
1. יוצרים תיקייה `episodes/s01e02/` עם `images/` (התמונות) ו-`voice_raw/` (הקלטה לכל משפט).
2. מעתיקים את `episodes/s01e01/episode.yaml` ומעדכנים:
   - **narration.lines**: לכל שורה קובץ ההקלטה, הטקסט המדויק (` / ` בין משפטים) והכתוביות (`|` בין כתוביות, `*מילה*` להדגשה).
   - **shots**: איזו תמונה נכנסת על איזו מילה (`at: "L3:נתלים"`), תנועת מצלמה (`cam`), לוק (`grade`).
   - **music / sfx / duck**: קטעי המוזיקה, האפקטים ומתי להנמיך.
3. מרנדרים:
```bash
python3 engine/reel.py episodes/s01e02 --timing-only   # בדיקת זמנים מהירה (שנייה)
python3 engine/reel.py episodes/s01e02 --frame 12.5    # פריים בודד לבדיקה
python3 engine/reel.py episodes/s01e02 --preview       # הכול + דף תמונות
```

### זמנים
`"L3:נתלים"` הרגע שהמילה נאמרת · `"L3:נתלים.end"` סוף המילה · `"L1:start"` / `"L1:end"` · `"S02"` תחילת שוט · `"+0.3"` / `"-0.2"` היסט · שמות מ-`marks`.
אם המנוע לא מוצא לבד את ההפסקות בין המשפטים, מוסיפים לשורה `splits: [שניות]` (כמו בשורה 6 בפרק 1).

### לוקים (`grade`)
`cool` מונטה קרלו, קריר ומלוטש · `warm` ילדות בנתניה, חם ומאובק (עם `haze`) · `warm_clean` הווה חמים · `green` הבית הנטוש, כהה וירקרק · `exposure` להבהרת תמונה כהה.

### אפקטים
- **שוט:** `handheld` (מצלמת יד) · `freeze` (פריים קפוא עם חץ ותווית בכתב יד).
- **סאונד:** `engine` · `freewheel` · `rustle` · `crinkle` · `creak` · `steps_light` / `steps_heavy` · `boom` · `shutter` · `room_tone` · `drips` · `lighter` · `bubbles` · `whoosh` · `tick`.
- **מוזיקה:** `intro` · `groove` · `tension` · `freeze` · `warm` · `dark`, ובנוסף `stop` (הקפאה) ו-`tapestop` (האטה עד עצירה).

כל הסאונד והמוזיקה מסונתזים בקוד, מקוריים ובלי בעיות זכויות.

## זהות הסדרה: `series.yaml`
שם, צבעים, מילים שתמיד נצבעות (הירוק בירוק, חום בענבר) וטקסט כרטיס הסיום. משנים פעם אחת, וזה חל על כל הפרקים.

## קריינות
הקול של דין: **Callum** ב-ElevenLabs v4 דרך Higgsfield (`voice_id` בקובץ הפרק). כל שורה מוקלטת כקובץ נפרד.
כשהמילה דו-משמעית, מוסיפים ניקוד רק בטקסט שנשלח להקלטה, למשל `שָׁלֵו` או `חוּם`. הכתוביות נשארות בכתיב הרגיל.
רוצים להחליף קול, או להקליט בקול אמיתי? שמים קבצים חדשים ב-`voice_raw/` עם אותם שמות ומרנדרים שוב. הקאטים והכתוביות יזוזו לבד.

## דרישות
Python 3 + numpy, Pillow, PyYAML, ו-ffmpeg. הפונטים Heebo, Frank Ruhl Libre ו-Amatic SC (רישיון OFL) כלולים ב-`engine/fonts`.

# Nolela LINE · אתר עדשות מגע צבעוניות

אתר חנות ל-[Nolela LINE](https://www.facebook.com/NolelaLINE) (חיפה), עדשות מגע צבעוניות שנתיות.
האתר סטטי לגמרי (HTML, CSS ו-JavaScript בלי build ובלי שרת), בעברית ובערבית, ומותאם לנייד.

## מה יש באתר

| חלק | מה הוא עושה |
| --- | --- |
| הירו | עין בהדמיית WebGL שמחליפה צבע לפי הגוון שבוחרים. כל האתר מקבל את צבע הגוון שנבחר. |
| הקולקציה | 12 גוונים עם סינון לפי משפחת צבע ועוצמת מראה. במעבר עכבר רואים את העדשה עצמה. |
| חלון מוצר | תצוגה על עין כהה, על עין בהירה ושל העדשה, בחירת מספר (דיופטר) לכל עין, כמות ומפרט. |
| סל והזמנה | הסל נשמר בדפדפן. טופס פרטים עם בדיקת תקינות. ההזמנה נשלחת כהודעה מוכנה בוואטסאפ (או באינסטגרם, עד שמגדירים מספר). |
| שאלון התאמה | צבע עיניים, מראה רצוי וגוון עור. שלוש המלצות מוצגות על צבע העיניים של הלקוחה. |
| מדידה וירטואלית | מעלים סלפי ומקישים על שתי העיניים. האתר מאתר את הקשתית ומלביש את העדשה. התמונה לא יוצאת מהמכשיר. |
| אנטומיה של עדשה | הסבר למה העדשות נראות טבעיות. |
| מדריך טיפול | הרכבה, הוצאה, ניקוי ובטיחות, ומחשבון "מתי מחליפים" לעדשה שנתית. |
| שאלות נפוצות, קהילה, פוטר | כולל קישורים לאינסטגרם ולפייסבוק. |
| נגישות | תפריט נגישות, ניווט מלא במקלדת, ערכה כהה, כיבוד "הפחתת תנועה", הצהרת נגישות. |
| מסמכים | תקנון, מדיניות פרטיות, הצהרת נגישות, משלוחים והחזרות. |

כל התמונות של העיניים והעדשות נוצרות בקוד (`assets/js/iris.js`), כך שאין תלות בתמונות סטוק, ותמונה חדה נוצרת לכל גוון שמוסיפים.

## מבנה הקבצים

```
index.html                 מבנה העמוד והטקסט בעברית
assets/css/styles.css      עיצוב (ערכה בהירה וכהה, RTL, נייד)
assets/js/config.js        פרטי העסק: וואטסאפ, רשתות, משלוחים, פרטים לתקנון
assets/js/products.js      הקטלוג: גוונים, מחירים, מפרט, אביזרים
assets/js/i18n.js          תרגום לערבית וטקסטים דינמיים
assets/js/legal.js         תקנון, פרטיות, נגישות, משלוחים
assets/js/iris.js          מנוע ההדמיה (WebGL, עם גיבוי Canvas)
assets/js/tryon.js         המדידה הווירטואלית
assets/js/app.js           כל ההתנהגות: סל, הזמנה, שאלון, שפה, נגישות
assets/img/                אייקונים ותמונת שיתוף (og-image.jpg)
tools/og.html              מקור תמונת השיתוף והאייקון
tools/build-preview.mjs    בניית קובץ תצוגה אחד (dist/preview.html)
```

## לפני שעולים לאוויר

- [ ] **וואטסאפ:** להזין מספר ב-`config.js` → `whatsapp: '9725XXXXXXXX'` (בלי + ובלי מקפים). ברגע שיש מספר, כפתור ההזמנה והכפתור הצף עוברים לוואטסאפ.
- [ ] **מוצרים ומחירים:** לעדכן ב-`products.js` את השמות, המחירים (כרגע 179 ₪ לכל גוון), האביזרים וזמינות עם מספר.
- [ ] **מפרט:** קוטר, קימור, תכולת מים וחומר (`specs`) הם ערכים נפוצים לעדשות שנתיות. לוודא מול המותגים שנמכרים בפועל.
- [ ] **משלוחים:** זמן אספקה ב-`config.js` → `shipping.days` (כרגע 2–5 ימי עסקים).
- [ ] **פרטי העסק לתקנון:** `business` ב-`config.js` (שם, ע.מ/ח.פ, כתובת, דוא״ל, רכז/ת נגישות). שדות ריקים מסומנים בצהוב בתוך המסמכים.
- [ ] **אישור משפטי:** לתת לעורך/ת דין לעבור על התקנון ומדיניות הפרטיות ב-`legal.js`.
- [ ] **נתונים:** 98% ממליצים, 85 ביקורות ו-18K עוקבים נלקחו מהעמודים הציבוריים. לעדכן ב-`config.js` כשמשתנה.
- [ ] **דומיין:** להחליף את `https://www.example.co.il` ב-`robots.txt` וב-`sitemap.xml`, ולהוסיף `<link rel="canonical">` ו-`og:url` עם הכתובת המלאה ב-`index.html`.
- [ ] **ערבית:** מצאנו גם חשבון אינסטגרם `@nolelaline` ("west bank"). אם הוא של העסק, אפשר להוסיף אותו לגרסה בערבית.

## הוספת גוון חדש

מוסיפים אובייקט ל-`lenses` ב-`products.js`:

```js
{
  id: 'hazel-gold',                       // מזהה באנגלית, ייחודי
  family: 'honey',                        // honey | brown | grey | green | blue
  name: { he: 'לוז זהוב', ar: 'بندقي ذهبي', en: 'Hazel Gold' },
  desc: { he: '...', ar: '...' },
  effect: 1,                              // 1 טבעי · 2 בולט · 3 דרמטי
  effD: 1.6, effL: 1.4,                   // עוצמת השינוי על עין כהה / בהירה (1–3), לשאלון
  warmth: 'warm',                         // warm | neutral | cool
  price: 179, power: true, gdia: '13.8',
  colors: { inner: '#d8a24a', mid: '#8d6b3a', outer: '#6a5a34', ring: '#2a2216' },
  seed: 0.44                              // מספר בין 0 ל-1, משנה את דוגמת הסיבים
}
```

`colors` הם צבעי ההדפס מהאישון החוצה. ההדמיה, הכפתורים וצבע האתר נגזרים מהם אוטומטית.

## העלאה לאוויר

האתר סטטי, אז אפשר לארח אותו כמעט בכל מקום:

- **Netlify:** לגרור את התיקייה `nolela-line` ל-[app.netlify.com/drop](https://app.netlify.com/drop), ואז לחבר דומיין.
- **Vercel / Cloudflare Pages / GitHub Pages:** לחבר את הריפו ולהגדיר את `nolela-line` כתיקיית השורש. אין פקודת build.
- **כל אחסון רגיל:** להעלות את תוכן התיקייה לשורש האתר.

בדיקה מקומית: `npx serve nolela-line` ולפתוח את הכתובת שמודפסת.

## הרחבות אפשריות

- **תשלום באשראי באתר:** לחבר עמוד תשלום של Grow (משולם), PayPlus, Cardcom או Tranzila. כפתור "שליחת ההזמנה" הוא המקום להפנות אליו.
- **ניהול מלאי והזמנות:** להעביר את העיצוב ל-Shopify או Wix אם הלקוחה רוצה ממשק ניהול.
- **מדידה:** Google Analytics 4 או Meta Pixel. להוסיף לפני `</head>`, יחד עם הודעת עוגיות.
- **תמונות לקוחות:** צילומים אמיתיים מהאינסטגרם (באישור) מחזקים מאוד את האמון, ומתאימים לאזור הקהילה.

יוצר `dist/preview.html`: כל ה-CSS וה-JS בקובץ אחד, בלי עטיפת `<html>` (בשביל כלי תצוגה שעוטפים את הדף בעצמם).
